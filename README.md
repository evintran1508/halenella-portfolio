# Halenella — Visual Storyteller & Creator Portfolio (Project 2)

A production-grade, interactive portfolio crafted with React 19, TypeScript, Tailwind CSS v4, GSAP, and Lenis, accurately recreating the 10-slide editorial presentation deck from the design reference.

## 🌟 Key Features & Animations

### 1. Dual Viewing Modes
- **📺 Presentation Deck Mode:** Interactive 1-by-1 slide deck navigation faithfully reflecting the Canva/Figma presentation layout from the reference image. Supports keyboard controls (`←` / `→` / `Space`), touch swipe on mobile, auto-slideshow, and fullscreen toggle.
- **🌐 Continuous Scroll Mode:** Seamless vertical website scroll enhanced by Lenis smooth scrolling, GSAP ScrollTrigger reveals, and floating scrollspy navigation pills.

### 2. 10 Implemented Slides (Accurately Matching the Reference)
1. **Hero Slide — "Portfolio":** Playful bold typography, floating retro cassette tape (with rotating spools), spatial studio headphones, spinning vinyl record, director clapperboard, and handwritten doodle callouts (`social media`, `video editor`, `brand collaboration`, `graphic designer`).
2. **About Me:** Casual seated portrait with fashion books, circular spinning watermark badge (`JUST EDITING • IT'S VIBING WITH VISUALS •`), bio narrative, and creator experience metrics.
3. **Education Background:** 3 authentic Polaroid photos with realistic drop shadows, tilted angles, and Cambridge/Harvard degree timeline milestones.
4. **Skills & Expertise:** Tool badges (Photoshop, Illustrator, Slack, Canva, Premiere Pro, Figma), camera portrait, and core strategy pillars.
5. **Velora Beauty (Previous Projects):** 3x3 aesthetic social media grid with high-resolution lightbox modal detailing audience impact metrics (`+340% Engagement Surge`).
6. **Social Accounts:** 3 smartphone mockups (Instagram Reel, TikTok viral video, YouTube Shorts) with animated follower statistics (2.4M, 3.8M, 850K).
7. **Brands Showcase:** Marquee brand logos (`maslostudio`, `fuse`, `florica`, `unearth`, `LULIZZI`) and 5 vertical smartphone reel cards.
8. **Working Experience:** 3-column timeline progression across Content Photography (2026), Video Editing (2025), and Global Brand Ambassadorship (2027-Present).
9. **Passion Project:** MacBook Pro mockup with realistic camera viewfinder HUD (`[REC ● 4K 60FPS]`, grid, aperture) and Lumière Beauty identity system.
10. **Let's Work Together:** Bold statement header, direct social channels, copy-email toast, and interactive collaboration booking modal with confetti burst.

### 3. Extra Interactive Touches
- **Ambient Lo-Fi Audio Player:** Built-in Web Audio API synthesizer that plays warm chill jazz chords without requiring external MP3 files.
- **Custom Precision Cursor:** Smooth follower star and interactive magnetic hover feedback.
- **Case Study Lightbox:** Click any project to open detailed campaign briefs.
- **Interactive Confetti:** Submission triggers celebratory fireworks.

## 🛠️ Tech Stack
- **Framework:** React 19 + TypeScript + Vite 8
- **Styling:** Tailwind CSS v4 with `@tailwindcss/vite`
- **Animations:** GSAP 3.12 (ScrollTrigger, Timelines) + Lenis Smooth Scroll
- **Icons & Visuals:** Lucide React + custom SVG brand icons
- **Effects:** Canvas Confetti + Web Audio API
